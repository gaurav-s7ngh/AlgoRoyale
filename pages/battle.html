⚔ PROBLEM #047 — BINARY SEARCH
ARRAY MEDIUM 10 MIN O(LOG N) REQUIRED
Given a sorted array of integers and a target value, implement Binary Search to find and return the index of the target. Return -1 if the target does not exist in the array. Must achieve O(log n) time complexity.
INPUT: arr = [2, 5, 8, 12, 16, 23, 38, 45], target = 23
OUTPUT: 5  |  EXPECTED COMPLEXITY: O(log n) time, O(1) space
🤖 ALGO_MASTER — PLAYER 1
✓ ACCEPTED
def binary_search(arr, target):
  low, high = 0, len(arr) - 1
  while low <= high:
    mid = (low + high) // 2
    if arr[mid] == target:
      return mid
    elif arr[mid] < target:
      low = mid + 1
    else:
      high = mid - 1
  return -1
